# onekapisch/homebrew-tap

Homebrew casks for OneKapisch apps.

```sh
brew install --cask onekapisch/tap/mac-4-breakfast
```

| Cask | App |
|---|---|
| `mac-4-breakfast` | [Mac 4 Breakfast](https://www.mac4breakfast.app): menu bar battery health monitor for Mac, iPhone, iPad and AirPods |

The app updates itself (Sparkle), so `brew upgrade` is not needed. The cask always downloads the current notarized release from mac4breakfast.app.
